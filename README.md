Покрытие

| Папка | Запросов | Что проверяется |

| 01 Healthcheck | 1 | Сервис доступен (`GET /ping` → 201) |
| 02 Auth | 4 | Выдача токена, неверный логин/пароль, пустое тело |
| 03 Create Booking | 6 | Создание брони, необязательные поля, граничные значения, кириллица, JSON-схема, негатив (500) |
| 04 Get Booking | 9 | Список id, фильтры по имени/фамилии, получение по id, 404 для несуществующего и некорректного id |
| 05 Update Booking (PUT) | 4 | Обновление с Cookie-токеном и Basic, 403 без авторизации и с невалидным токеном |
| 06 Partial Update (PATCH) | 3 | Частичное обновление, остальные поля не меняются, 403 без авторизации |
| 07 Delete Booking | 3 | 403 без авторизации, удаление, 404 после удаления |
